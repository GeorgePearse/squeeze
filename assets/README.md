# Assets

Store reusable project images, diagrams, screenshots, and benchmark results here.
Use descriptive filenames and relative links from the README or other docs.

- `benchmarks/digits/` and `benchmarks/fashion-mnist/`: saved full-algorithm
  heatmaps and metric CSVs.
- `benchmarks/strategies/`: plots from the older strategy benchmark.
- `benchmarks/hybrid/`: exploratory hybrid comparison plots and CSVs.
- `images/`: reusable illustrations inherited from the original project.

Published documentation assets live in `docs/assets/`; embeddings, run protocols,
and reproducibility records live in `working_docs/`. Moving the saved results here
does not change their original measurements. Keep raw datasets, model weights,
and temporary build outputs out of this folder.
