Squeeze: Rust embedding experiments

1,797 handwritten digits, 64 raw pixel features, CPU only. Runtime includes graph construction, initialization and layout. Labels stratify Fashion-MNIST sampling and color the plots; no labels enter fitting. Values are medians with full seed ranges; repeated seeds are not independent datasets.

Trustworthiness uses scikit-learn's rank-based definition. Neighbor recall measures overlap and is reported separately. These results establish tradeoffs on the selected dataset, not a universal winner.
